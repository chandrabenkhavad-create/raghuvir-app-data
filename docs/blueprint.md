# **App Name**: DataLogger

## Core Features:

- Purchase Entry Form: A UI form for users to enter details of new purchases, including name, supplier, weights, driver, site and remarks. Includes a 'Submit' button to save the data, and a print option formatted for DL paper size.
- Diesel Entry Form: A UI form for users to enter details of diesel purchases, including vehicle number, liters, rate, amount, driver name, pump, and ODO meter reading. Includes a 'Submit' button to save the data.
- Report Generation: Generates reports in Excel format based on entries into the two forms, containing all the data in each of those forms.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to represent data integrity and professionalism.
- Background color: Light blue (#E3F2FD), a desaturated version of the primary, creating a calm and professional interface.
- Accent color: Purple (#7E57C2) to draw attention to important UI elements, such as the submit button.
- Font: 'Inter', a sans-serif font that will be used for both headlines and body text, suitable for a modern and objective data entry application.
- Use a clean and well-organized layout, to provide a good UX.
